- `UNRESOLVED` always carries a reason from the D39 set: every `unresolved()` call in the machine sets one of `ADVERSARY_UNAVAILABLE`, `TIMEOUT`, `BUDGET`, `MALFORMED_OUTPUT`, `DISAGREEMENT`; the property test asserts non-null; position-review rejects `UNRESOLVED` with a null reason. **Confirmed**, with two caveats recorded above: `REVISION_EXHAUSTED` is unreachable (#8) and the `ActionCycle` schema does not enforce the coupling (#8).
- The separation has one behavioral leak that is not a domain leak: position-review trusts any `CLEARED` as reviewed (#1).

### Check C — signed-envelope security summary

- Signature covers canonical `{algorithm, keyId, payload, signedAt}`; `payloadHash` is re-derived and never trusted (`signed-envelope.ts:68-74`); tests prove forged `payloadHash` cannot rescue a tampered payload. **Sound.**
- Unknown keys fail before signature checks; malformed meta fails closed. **Sound.**
- Canonical JSON: no exploitable ambiguity found; collisions listed in #13 are cross-type and unreachable through strict schemas. `__proto__` own-keys from `JSON.parse` are handled correctly by `Object.keys`; prototype-chain properties are ignored.
- Strictness: every top-level signed payload is `strictObject`; nested loose objects exist (#5). The digest cannot see strictness (#4).
- Ed25519 via WebCrypto with non-extractable keys by default; PKCS#8 export only on explicitly extractable keys. Not a wallet key path. **Sound.**

## Verdict

**Gate BLOCKED.** Three high findings are unresolved; each is a small, local change with a property test, and none touches a §31-protected decision.

Blocking items:

1. **#1** — `IGNORE` on an open-position cycle clears without adversarial review and is treated as `REVIEWED` (`libs/agents/src/action-cycle/machine.ts:129-131`, `libs/execution/src/state/position-review.ts:60-66`).
2. **#2** — landed transaction unrepresentable from `SIGNED_NOT_SUBMITTED`; exposure uncounted after crash-after-sign (`libs/execution/src/state/order-attempt.ts:87-99`).
3. **#3** — idempotency key released after `COMPLETED`; redelivery creates a second intent (`libs/execution/src/state/intent.ts:36-43`).

Recommended before re-review: also close #4, #5, #7 (they are contract/machine-local and cheap), record #11 and #12 as operator decisions, and add `coverage` to the invariant map (#9) so partial proofs are visible to the next reviewer.

What is good and should not be regressed: canonical JSON and envelope verification are sound; terminal states are absorbing and property-tested across random interleavings; `PAUSED` stickiness and live-arming preconditions are enforced in one place; the boundary lint is real (verified by negative probes); the D39 handoff between the two machines is a genuine two-domain design with no position behavior in the action cycle (ADR-0001 confirmed).
