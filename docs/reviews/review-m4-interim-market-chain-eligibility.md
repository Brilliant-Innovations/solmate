## Residuals (out of M4 scope or accepted, to carry forward)

- A failed chain read skips a held position without any record; nothing marks a position's safety evaluation as stale, so a long RPC outage leaves `safety_state` frozen at its last value (`held-asset-safety.ts:72-78`). M5a's `PROTECTION_ONLY` logic should treat "no evaluation within `maxChainReadAgeMs`" as DEGRADED.
- Reconciliation `UNAVAILABLE` (chain read failed) never pauses; consecutive `UNAVAILABLE` cycles are indistinguishable from "clean" to anything that reads only the latest status. D63/`STARTING` must require a *recent* `CLEAN`, not merely "no MISMATCH".
- Inbound funding to the trading wallet is `UNKNOWN_MOVEMENT` today (no `FUNDING` lifecycle); the §39.3 funding flow must register a lifecycle before the first real deposit or every deposit pauses trading.
- Multi-hop swaps through an intermediate token that the tracked wallet's own ATA receives and forwards derive as four transfers, not a BUY (`derive.ts:97-108`); acceptable under-detection, worth a fixture.
- Wallet-event retention (≈300 events / 2 min from one bot wallet, author's measurement) is unaddressed; `tracking_active` is a manual switch, not a policy.
- Helius `transactionHistory` mixes `paginationToken` with a moving `afterSignature` (`tracked-wallets.ts:71-74`); idempotent inserts hide duplicates, but a skipped page is possible if the token encodes a position relative to the original query.
- `readMintChainState` spans three RPC calls at possibly different slots and reports the minimum; `top1..top20` can exceed `supply` transiently (`Fraction` max 1 would then fail a strict parse — no strict parse exists on that path today).
- `SafetyPolicy.transferFeeRaiseBps` 100 lets a fee go 0 → 100 bps unflagged while `EligibilityPolicy.maxTransferFeeBps` is also 100; consistent, but worth an explicit note in the policy.
- The local Supabase stack contains integration-test residue and an unscoped `STARTING` runtime session; the review's live checks therefore rest on the author's hosted evidence for anything that needs real provider data.
